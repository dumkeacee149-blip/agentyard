## Headliners

- **[MCP Inspector 2.13.0](https://github.com/modelcontextprotocol/inspector/releases/tag/2.13.0)** (Oct 28). Follow-up to the eMudhra CA compromise: Inspector trusts whatever Node.js you run, so `npx` users need Node **22.23.4 / 24.22.1 / 26.12.1+** (the Docker image already ships 22.23.4). Also bumps `undici` and `fast-uri`, adds load-test thresholds for the CLI/`mcpdo`, and tightens OAuth destination checks. [Directory entry](/directory/mcp-inspector)
- **[Codex CLI 0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0)** (Oct 29). GPT-6.1 Terra lands in the bundled, Vertex and Bedrock catalogs. The TUI gets keyboard-driven transcript selection (word/line/page + search), clearer safety-block follow-ups, `codex exec --resume`, and `codex doctor --network-only`. Earlier in the week: [0.165.0](https://github.com/openai/codex/releases/tag/rust-v0.165.0) (Vertex provider, memory v2 default) and [0.164.0](https://github.com/openai/codex/releases/tag/rust-v0.164.0) (`/presets`, inline `/model`/`/permissions`, credential masking). [Directory entry](/directory/codex-cli)
- **[OpenClaw 2026.10.9](https://github.com/openclaw/openclaw/releases/tag/v2026.10.9)** (Oct 29). Security-minded stable: patches `fast-uri`, oversized Zod collections, IMAP sender parsing and MSAL Node; applies `tools.fs.workspaceOnly` to Gateway-built tools; keeps live credentials out of MCP CLI inspection; makes failed update rollbacks safer. Prefer the tag notes before upgrading a self-hosted Gateway. Also in-window: [2026.10.7](https://github.com/openclaw/openclaw/releases/tag/v2026.10.7) (replay-safe session recovery) and [2026.10.8](https://github.com/openclaw/openclaw/releases/tag/v2026.10.8). [Directory entry](/directory/openclaw)

## One thing to try

Point your coding agent at **[MDN MCP](/directory/mdn-mcp)** (`mcp.mdn.mozilla.net`) when it touches web platform APIs. It’s Mozilla’s experimental hosted server with live MDN + Baseline compatibility data, so the agent stops quoting training-cutoff docs for CSS and Web APIs.
