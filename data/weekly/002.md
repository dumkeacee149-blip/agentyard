## Headliners

- **[MCP Inspector 2.12.0](https://github.com/modelcontextprotocol/inspector/releases/tag/2.12.0)** (Oct 21). Security release for every v2 build from 2.0.0 through 2.11.0. URL opens are limited to `http(s)` and use the checked URL (blocks Windows/WSL command execution via OAuth authorize URLs), the production server validates `Host` against an allow-list (DNS rebinding), and `/api/fetch` caps upstream bodies at 4 MiB. Upgrade with `npx @modelcontextprotocol/inspector@latest`. [Directory entry](/directory/mcp-inspector)
- **[FastMCP 4.1.3](https://github.com/PrefectHQ/fastmcp/releases/tag/v4.1.3)** (Oct 20). Pins certifi to 2026.10.19+ after the eMudhra CA compromise, and fixes public-client OAuth, empty visibility selections, generator transforms and per-server request timeouts. FastMCP 4 trusts the system store by default: updating the package alone is not enough, so follow the [security notice](https://github.com/PrefectHQ/fastmcp/blob/main/SECURITY.md#certificate-authority-incident-october-2026) for OS, container, custom and installer trust stores. [Directory entry](/directory/fastmcp)
- **[OpenClaw 2026.10.5](https://github.com/openclaw/openclaw/releases/tag/v2026.10.5)** (Oct 18). A large stable drop (thousands of commits). Prefer the human [release notes](https://docs.openclaw.ai/releases/2026.10.5) or the agent-oriented [changelog](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.10.5.md) before you upgrade a self-hosted Gateway. [Directory entry](/directory/openclaw)

## Coding agents

- **[Claude Code v2.1.307](https://github.com/anthropics/claude-code/releases/tag/v2.1.307)** (Oct 21) adds `/claude-api api-version` for API version `2026-10-21`, and a `claude_code.safety_event` OpenTelemetry event whenever a permission rule, auto mode, safety check, hook or sandbox stops, prompts or sends a tool call back. Also fixes locked-keychain MCP auth messaging on macOS, sleep-during-connect timeouts, duplicate HTTP MCP retries on mid-call disconnects, and several autocompact edge cases. Latest patch is [v2.1.308](https://github.com/anthropics/claude-code/releases/tag/v2.1.308). [Entry](/directory/claude-code)
- **[Hermes Agent v0.22.3](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.3)** (Oct 21) rolls ~620 PRs since v0.22.2 into a stable CLI, installer, Microsoft Store, Docker and Cloud build. Curated notes for that window ship with v0.23.0; this tag is the one to install if you want the accumulated fixes now. [Entry](/directory/hermes-agent)
- **[OpenHands v1.30.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.30.0)** (Oct 22) plus [v1.29.0](https://github.com/OpenHands/OpenHands/releases/tag/v1.29.0) (Oct 20): automation setup reflects built-in integration connection state, and launchers can read public skills from the bundled extensions package. [Entry](/directory/openhands)
- **[Qwen Code v0.26.0](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.0)** (Oct 21) ships alongside Desktop and CUA driver builds with the same version. [Entry](/directory/qwen-code)
- **[Cline](https://github.com/cline/cline/releases)** (Oct 17) CLI `v3.0.73` / Desktop `v0.0.48`: GPT-6-style OpenAI-compatible models send `max_completion_tokens`, and the Cline provider default returns to Claude Sonnet 5.5. [Entry](/directory/cline)
- Also shipped: [Kilo Code v7.8.15](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.15), Concord MCP [v0.15.0](https://github.com/Get-Concord-AI/concord-mcp/releases/tag/v0.15.0) (first-class Google Antigravity plus Copilot CLI), and OpenCode stayed on the 1.x line with [v1.19.3](https://github.com/anomalyco/opencode/releases/tag/v1.19.3).

## One thing to try

If you run **[MCP Inspector](/directory/mcp-inspector)** against remote servers, jump to **2.12.0** before the next debug session. The Host allow-list and URL-open fixes close paths that older v2 builds left open; set `MCP_INSPECTOR_ALLOWED_HOSTS` if you put Inspector behind a reverse proxy that rewrites `Host`.
