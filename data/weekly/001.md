Welcome to the first AgentYard Weekly. Every Friday: what actually shipped across coding agents, MCP servers and agent tooling, with links to the release notes so you can check for yourself. Everything below was released between Oct 8 and Oct 15, 2026.

## Headliners

- **[Codex CLI 0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0)** (Oct 15). You can now send a follow-up while Codex is still responding to steer it mid-turn. A searchable `/config` screen, a configurable leader key in `/keymap`, and parallel execution of independent read-only tools (skills, memory and history lookups) also landed. [Directory entry](/directory/codex-cli)
- **[Chrome DevTools MCP 1.11.0](https://github.com/ChromeDevTools/chrome-devtools-mcp/releases/tag/chrome-devtools-mcp-v1.11.0)** (Oct 15). Adds screencast tools that need no ffmpeg and are on by default, a new heap-snapshot context analysis tool with pagination for snapshot comparisons, a flag to reject `file:` navigations, and config-file discovery with live reload. Lighthouse audits now return failing audits inline. [Directory entry](/directory/chrome-devtools-mcp)
- **[FastMCP 4.1.0](https://github.com/PrefectHQ/fastmcp/releases/tag/v4.1.0)** (Oct 8). Mostly a fix sweep across OpenAPI, proxies, auth, tasks and the CLI, plus Python 3.15 support. Read the notes before upgrading: some security fixes are stricter (OpenAPI path params reject `.`/`..`, skill files must stay inside their directories, and HTTP sessions now expire after 30 idle minutes). [Directory entry](/directory/fastmcp)

## Coding agents

- **[Claude Code v2.1.301](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)** (Oct 15) adds a cap on how long unattended retry mode waits on a usage limit, the `%` bracket-matching motion in vim mode, and richer OpenTelemetry fields that tell auto-mode classifier decisions apart from permission rules. [Entry](/directory/claude-code)
- **[OpenClaw 2026.10.4](https://github.com/openclaw/openclaw/releases/tag/v2026.10.4)** is a stability patch: the Gateway survives sleep and clock jumps, shutdown no longer hangs, and an owner-impersonation path in Tlon group DMs was closed. Update if you self-host. [Entry](/directory/openclaw)
- **[Hermes Agent v0.22.2](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.2)** (Oct 15) replaces v0.22.1, which was built from the wrong commit. It fixes gateways that refused to start after a reboot and makes long local-model turns more robust on laptops. [Entry](/directory/hermes-agent)
- **[goose v1.54.0](https://github.com/aaif-goose/goose/releases/tag/v1.54.0)** (Oct 8) adds HTML session export with an interactive viewer and a goose-mode prompt during first-time setup. [Entry](/directory/goose)
- **[Qwen Code v0.25.2](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.2)** (Oct 15) ships more managed-agent team plumbing and TypeScript authoring for headless Mods. [Entry](/directory/qwen-code)
- Also shipped: [Kilo Code v7.8.12](https://github.com/Kilo-Org/kilocode/releases/tag/v7.8.12), [Cline v4.1.24](https://github.com/cline/cline/releases/tag/v4.1.24), [Crush v0.98.1](https://github.com/charmbracelet/crush/releases/tag/v0.98.1) and [OpenCode v2.0.30](https://github.com/anomalyco/opencode/releases/tag/v2.0.30).

## One thing to try

If your agent edits frontend code, give it **[Chrome DevTools MCP](/directory/chrome-devtools-mcp)** next to **[Playwright MCP](/directory/playwright-mcp)**. Playwright handles driving the page; DevTools lets the agent read console errors, network waterfalls and performance traces, so it checks its own work instead of asking you for screenshots.
